# Play 스토어 배포 가이드

`오늘 뭐 먹지` 안드로이드 앱을 빌드하고 Google Play에 올리는 순서.

앱은 `../index.html`(웹 원본)을 그대로 감싼 Capacitor 앱이다. 웹을 고치면
`npm run sync`로 앱에 반영한다. 웹과 앱의 레시피는 항상 같은 파일에서 나온다.

---

## 1. 서명 키 만들기 (최초 1회, 직접 실행)

AAB로 올리면 Play 앱 서명이 적용된다. 구글이 실제 서명 키를 보관하고,
여기서 만드는 키는 **업로드 키** 역할을 한다. 잃어버려도 구글에 재설정을
요청할 수 있어 앱이 영영 막히지는 않는다. 다만 재설정은 며칠 걸리는
번거로운 절차이므로 비밀번호와 함께 안전한 곳에 백업해 둘 것.

```bash
keytool -genkeypair -v -keystore C:/Users/user/.android/what-to-eat-release.keystore -alias what-to-eat -keyalg RSA -keysize 2048 -validity 10000
```

물어보는 것들: 비밀번호(2번), 이름/조직/도시/국가(대충 적어도 되지만 국가는 `KR`).

키 파일은 저장소 바깥이면 어디든 좋다. `.android/`는 SDK 도구가 관리하는
폴더라 Studio 문제를 고치려고 통째로 지우는 일이 가끔 있으니, 백업만
따로 챙겨두면 된다.

그다음 `android/` 폴더에 `keystore.properties`를 만든다:

```properties
storeFile=C:/Users/user/.android/what-to-eat-release.keystore
storePassword=아까_입력한_비밀번호
keyAlias=what-to-eat
keyPassword=아까_입력한_비밀번호
```

- 경로는 절대경로도 되고, `android/` 기준 상대경로도 된다
- **역슬래시 대신 슬래시(`/`)를 쓸 것.** properties 파일에서 `\`는
  이스케이프 문자라 `\Users`가 깨진 유니코드로 읽힌다

`keystore.properties`와 `*.keystore`는 `.gitignore`에 들어 있어 커밋되지
않는다. 확인:

```bash
git status --short
```

## 2. 빌드

```bash
npm run sync
cd android && ./gradlew bundleRelease
```

결과물: `android/app/build/outputs/bundle/release/app-release.aab` — 이 파일을 Play에 올린다.

APK로 실기기에서 먼저 확인하려면:

```bash
cd android && ./gradlew assembleDebug
adb install app/build/outputs/apk/debug/app-debug.apk
```

## 3. 버전 올리기

레시피를 고치고 새로 올릴 때마다 `android/app/build.gradle`에서:

- `versionCode` — 정수, **반드시 이전보다 커야 한다** (1 → 2 → 3)
- `versionName` — 사람이 보는 버전 ("1.0.0" → "1.0.1")

## 인터넷 권한에 대하여

매니페스트에 `android.permission.INTERNET`이 선언돼 있다. Capacitor가 기본으로
넣는 항목이고, 앱이 실제로 외부와 통신하지는 않는다 (모든 자산이 앱 안에 있고,
네트워크를 끊은 상태에서 외부 요청 0건을 확인했다).

이 권한을 빼도 앱이 동작하는지는 **아직 확인하지 않았다.** Capacitor는 앱 화면을
`https://localhost`로 띄우는데, 이게 권한 없이도 되는지 실기기에서 검증이 필요하다.
빼고 싶다면 `android/app/src/main/AndroidManifest.xml`에서 해당 줄을 지우고
반드시 실기기에서 앱이 정상적으로 뜨는지 확인할 것. 안 뜨면 되돌리면 된다.
